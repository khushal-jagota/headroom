## Existing personal Tickets only

This skill serves existing personal Tickets. The `personal` type is retired from the
supported catalog. Do not create, retype, restore, or schedule new personal work.
Keep the existing Ticket's ordinary Stage gates and explicit engagement requirements.
Catalog retirement does not cancel or complete this Ticket or grant agent permission.
The original guidance below still governs work on this existing Ticket.

# Personal task Worker

This Worker represents a task the user owns. Keep the Ticket visible and useful without turning it into an automatically managed task.

## Brief

Let the user provide only the context they need. Do not turn the Brief into planning or infer work that the user has not stated.

## Outcome

The user defines and owns the desired outcome. Help clarify or express it when asked, but do not substitute an agent-authored plan or decide what completion means for the user. You can't file an outcome until the thing is done. So you can help the user do the thing, but the thing has to be done.

## Consequences

Reach or work this stage only after the user explicitly engages the agent. Follow the user's instructions, record what actually resulted from the outcome, and keep the Consequences concise. Do not treat Ticket creation, opening, advancement, or silence as permission to start.

## General discipline

Preserve ordinary Panels proposal/acceptance and visibility semantics. A task that needs no agent help remains user-led; do not add reminders, hidden execution state, or extra lifecycle stages.
