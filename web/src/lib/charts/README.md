These components come from the approved `integrated-component-sources` payload in the goal-page design, `goals-wireframe-v15.html`.

The line plot, counter, gauge, completion animation, supporting disclosure, and motion presets retain that source's interaction design. `GoalChart.tsx` replaces its sample-data adapter with the canonical goal/page contract. Chart.js comes from the locked npm dependency, with its upstream MIT license in the package.

The host supplies available content width. `presentation.ts` preserves dated identities, signed readings, explicit gaps, and authored reference paths. Range and disclosure preferences belong to the goal and stable block ID in session storage. Measurement writes are outside this renderer.

Sheet coverage additions use the approved `chart-components.html` `component-sources` payload. `components/goal-indicators.tsx` adapts `ProgressCard`, `TimeBudgetCard`, and `AllocationCard` from that payload's file of the same name; `components/bar-chart.tsx` adapts its `app.tsx` `BarCard` for both periods and stacked composition. The imported meter/ring geometry, segment inspection, DOM legends, and motion remain; sample selectors, fixture values, and page/gallery chrome do not. Host token aliases replace the prototype's literal colors.

Authored category series share observation identity. Stacked and allocation totals are unknown if any category lacks that observation. Sum headlines add known readings in the selected range, identify partial ranges, and remain missing when no readings exist. Hover/keyboard inspection shows the individual observation; canonical goal/table summaries independently use all time. Range targets override the chart target where authored. Floor labels, percentage-point differences, and warning comparisons are contract options, rather than inferred from title text. Indicator inputs do not add measurement-write APIs.

Reading suffixes resolve in `presentation.ts`. An explicit `format.suffix` stays literal, including an empty string. Otherwise, units that start with a Unicode letter receive one ASCII space. Existing whitespace and symbol units stay literal. Counters and gauges use the same suffix. Gauge unit spans preserve its whitespace. Prefixes, numeric precision, compact axis `k`, and axes that omit word units retain their behavior.
