Panels · ACP conversation

The chat panel, taken apart

Every distinct thing the conversation panel can render today, drawn with the app's own tokens and CSS so it looks the way it ships. Each specimen has an ID — point at one (say, D2) and tell me what you'd change. The last section lists data the wire already carries that the UI never shows.

E Plan

The agent's TODO list. Sent whole each time (plan), replaced in place, cleared by plan_removed. It renders inline in the transcript wherever it arrived — it does not pin.

status and priority are mono words above each entry — no checkmarks, no progress count, no strikethrough on done items. Newer plan_update / plan_removed variants also exist on the wire.
interactions
none
