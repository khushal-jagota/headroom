Live server connection status

The connection signal stays at the navigation’s far-right edge and remains separate from worker presence. Use the controls to inspect each state; production behavior changes these automatically.

  • ConnectedQuiet confirmation. A healthy heartbeat keeps this state current.
  • ReconnectingShown as soon as a known connection is interrupted and while automatic retries are active.
  • OfflineClear failure state after liveness is lost beyond the retry grace period; no claim about the server process itself.
