Embeds

How linked files sit inside content — a ticket field, a proposal, a chat message. One primitive: a whisper header (name · kind · open ›), then the thing itself, recessed. Supporting material never rises above the page; only the ask is raised.

The result links the artifacts inline. Every embed is the same container: the bar at the top — name · kind · action — with the content on it. A plain link like hero-final.png:

An HTML file is a window, not a card — the frame gets real height, the page renders inside it, and it can grow in place when you want to read rather than glance:

waitlist-mockup.htmlhtmlopen full ›

A linked markdown file expands into the page as another document's words — serif like everything said, one tint quieter than the host so the boundary stays legible:
